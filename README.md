# CoinGecko Java SDK — unofficial FlowSDK demo

> **Unofficial.** This project is not affiliated with, endorsed by or supported by CoinGecko. It shows what a Java SDK generated by **FlowSDK** looks like, using CoinGecko's public, MIT-licensed [OpenAPI description](https://github.com/coingecko/coingecko-api-oas). For production use, prefer CoinGecko's official clients.

A typed Java 17+ client for the CoinGecko Demo API 3.0.0:

- **66 operations** with typed parameters and responses, and **350 model types**: immutable Java records with builders, and enums.
- **One dependency:** Jackson. HTTP goes through the JDK's own `HttpClient`.
- **Errors you can handle:** every non-2xx response throws `ApiException` with the status code, headers and body.
- **Forward compatible:** enum values and union variants CoinGecko adds later decode to `UNKNOWN` instead of failing.
- **Safe defaults:** connect and request timeouts, a response size cap, an immutable and thread-safe client.
- **Traceable:** `openapi/coingecko-demo-api.json` is the exact description the code was generated from.

## Quick start

Requirements: JDK 17 or later and Maven.

```bash
mvn -B package
mvn -B -q dependency:build-classpath -Dmdep.outputFile=cp.txt
mkdir -p target/examples
javac -d target/examples -cp "target/coingecko-java-1.0.0.jar:$(cat cp.txt)" examples/QuickStart.java
java -cp "target/examples:target/coingecko-java-1.0.0.jar:$(cat cp.txt)" QuickStart
```

On Windows, separate classpath entries with `;` instead of `:`.

## Usage

```java
import com.getflowsdk.demo.coingecko.CoinGeckoDemoApiClient;
import com.getflowsdk.demo.coingecko.api.DefaultApi;
import com.getflowsdk.demo.coingecko.model.CoinsMarketsItem;

DefaultApi api = CoinGeckoDemoApiClient.builder()
        .headerAuth(System.getenv("COINGECKO_DEMO_API_KEY"))
        .build()
        .defaultApi();

for (CoinsMarketsItem coin : api.coinsMarkets("usd")) {
    System.out.println(coin.name() + ": " + coin.currentPrice() + " USD");
}
```

CoinGecko's Demo plan uses a free API key, sent here in the `x-cg-demo-api-key` header. The example also runs without one, at the public endpoint's lower rate limit.

Each operation has three forms: `op(...)` returns the decoded body, `opWithHttpInfo(...)` returns an `ApiResponse<T>` with status and headers, and, when the operation has optional parameters, `op(required...)` omits them.

CoinGecko's description groups no operations by tag, so all 66 are methods of `DefaultApi`. With an API that uses tags, each tag becomes its own class (`CoinsApi`, `ExchangesApi`, ...).

## Authentication

| Scheme | Builder method | Sent as |
|---|---|---|
| headerAuth | `headerAuth(...)` | API key in header `x-cg-demo-api-key` |
| queryAuth | `queryAuth(...)` | API key in query `x_cg_demo_api_key` |

Tokens can be passed as a `Supplier<String>` to refresh them on every request. Custom schemes can implement `Authentication` and be registered with `authentication(name, auth)`.

## Errors

Every non-2xx response throws `ApiException` with `statusCode()`, `headers()`, `responseBody()` and, when the API declares an error schema, `errorBody(Type.class)`. Transport failures and timeouts throw `ApiException` with status 0. Exception messages never contain response bodies, so they are safe to log.

Enum values and union variants added to the API later deserialize to `UNKNOWN` and `Unknown` instead of failing, so older SDK versions keep working.

## About FlowSDK

FlowSDK turns an OpenAPI or Swagger description into a complete Java SDK, then keeps it in step with the API as it changes. This repository is a demonstration; the SDK in it is not maintained against CoinGecko's API.
